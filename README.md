# Auto-center-veloz
Site de acompanhamento de serviços da Auto Center Veloz

Projeto desenvolvido para o Estudo de Caso 3 da disciplina Design Profissional. A proposta é um site simples para melhorar a comunicação entre a oficina e seus clientes, permitindo acompanhar o veículo, o status do serviço e o orçamento. O protótipo foi desenvolvido com HTML e CSS e possui apenas funções visuais. O projeto está organizado com `index.html`, `style.css`, `README.md`, `LICENSE` e `.gitignore`.
